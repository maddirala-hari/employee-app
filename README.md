# Employee App

## Project Overview
A simple Node.js and Express application created to practise Git, GitHub, Jenkins CI/CD, and AWS EC2 deployment.

## Technologies
- Node.js
- Express.js
- Git and GitHub
- Jenkins
- AWS EC2

## Application Endpoints
- `/` — Displays a welcome message.
- `/employees` — Returns employee details in JSON format.

## Learning Objectives
- Manage source code using Git and GitHub.
- Understand Jenkins pipeline configuration.
- Install dependencies and run a Node.js application.
- Practise deployment and troubleshooting on AWS EC2.
